# UI Review Artifacts

Create one folder per feature or screen:

```text
.design/<feature-slug>/
├── DESIGN_BRIEF.md
├── screenshots/
│   ├── before-desktop-1280.png
│   ├── before-mobile-390.png
│   ├── after-desktop-1280.png
│   └── after-mobile-390.png
└── DESIGN_REVIEW.md
```

Do not commit screenshots containing secrets, personal data, access tokens, customer information, or private generated images. Use sanitized fixtures when the real screen contains sensitive data.
