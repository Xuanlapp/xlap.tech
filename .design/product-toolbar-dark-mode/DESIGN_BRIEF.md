# Product toolbar dark mode

- Goal: keep product workspace toolbar controls readable and contained in Tailwind dark mode.
- Scope: Sticker, Decal, Glass, and Suncatcher list toolbars, status tabs, empty states, and API menus.
- Preserve: Livewire bindings, Alpine interactions, routes, labels, and data behavior.
- Acceptance: controls use neutral dark surfaces, semantic action colors retain contrast, menus and status tabs remain readable, and no overflow is introduced.
